# 📚 중고 도서 교환 서비스 API

중고 도서 교환 서비스에서 사용하는 주요 URL과 기능을 정리한다.

---

## 1. 전체 API 목록

| 기능 | Method | URL | 설명 |
|---|---|---|---|
| 도서 목록 조회 | GET | `/books` | 등록된 전체 도서를 조회한다. |
| 도서 상세 조회 | GET | `/books/{id}` | 선택한 도서의 상세 정보를 조회한다. |
| 도서 등록 화면 | GET | `/books/new` | 새로운 도서를 등록하는 화면을 보여준다. |
| 도서 등록 | POST | `/books` | 새로운 도서를 등록한다. |
| 교환 요청 | POST | `/books/{id}/exchange` | 선택한 도서에 교환을 요청한다. |
| 교환 요청 목록 | GET | `/exchanges` | 등록된 교환 요청 목록을 조회한다. |

---

# 2. 도서 기능

## 2.1 도서 목록 조회

**Method**

`GET`

**URL**

`/books`

**설명**

등록된 전체 도서 목록을 조회한다.

도서 제목, 저자, 설명, 교환 상태 등을 확인할 수 있다.

---

## 2.2 도서 상세 조회

**Method**

`GET`

**URL**

`/books/{id}`

**설명**

선택한 도서의 상세 정보를 조회한다.

예를 들어 3번 도서를 조회한다면 다음 주소를 사용한다.

`/books/3`

---

## 2.3 도서 등록 화면

**Method**

`GET`

**URL**

`/books/new`

**설명**

새로운 도서를 등록하기 위한 입력 화면을 보여준다.

입력 정보:

- 도서 제목
- 저자
- 도서 설명

---

## 2.4 도서 등록

**Method**

`POST`

**URL**

`/books`

**설명**

사용자가 입력한 도서 정보를 데이터베이스에 저장한다.

새로 등록된 도서의 기본 상태는 다음과 같다.

`AVAILABLE`

즉, **교환 가능한 도서**로 등록된다.

---

# 3. 교환 요청 기능

## 3.1 교환 요청

**Method**

`POST`

**URL**

`/books/{id}/exchange`

**설명**

선택한 도서에 교환을 요청한다.

예를 들어 3번 도서에 교환을 요청하면:

`POST /books/3/exchange`

교환 요청이 생성되면서 다음과 같이 처리된다.

`exchange_request`

- `book_id` : 요청한 도서 번호
- `status` : `PENDING`

동시에 해당 도서의 상태는 다음과 같이 변경된다.

`AVAILABLE → REQUESTED`

---

## 3.2 교환 요청 목록 조회

**Method**

`GET`

**URL**

`/exchanges`

**설명**

현재 등록되어 있는 교환 요청 목록을 조회한다.

현재 확인할 수 있는 정보:

- 교환 요청 번호
- 요청한 도서 번호
- 교환 요청 상태

교환 요청 상태는 현재 다음 값을 사용한다.

| 상태 | 의미 |
|---|---|
| `PENDING` | 교환 요청 대기 중 |
| `ACCEPTED` | 교환 요청 수락 |
| `REJECTED` | 교환 요청 거절 |

---

# 4. 현재 구현 흐름

전체적인 서비스 동작은 다음과 같다.

`도서 등록 → 도서 목록 → 도서 상세 → 교환 요청 → 요청 목록`

교환 요청이 발생하면 데이터베이스에서는 다음과 같이 처리된다.

`도서 선택 → exchange_request 생성 → 상태 PENDING 저장 → book 상태 REQUESTED 변경`

# 5. 추가 구현 예정

회원 기능은 별도로 구현할 예정이다.

회원 기능이 추가되면 다음 정보를 구분할 수 있도록 확장한다.

- 도서를 등록한 회원
- 교환을 요청한 회원
- 내가 보낸 교환 요청
- 내가 받은 교환 요청
