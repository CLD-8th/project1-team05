\# 중고 도서 교환 서비스 API



\## 1. 도서 목록 조회



\- Method: GET

\- URL: /books

\- 설명: 등록된 도서 목록을 조회한다.



\## 2. 도서 상세 조회



\- Method: GET

\- URL: /books/{id}

\- 설명: 선택한 도서의 상세 정보를 조회한다.



\## 3. 도서 등록



\- Method: POST

\- URL: /books

\- 설명: 새로운 도서를 등록한다.



\## 4. 교환 요청



\- Method: POST

\- URL: /books/{id}/exchange

\- 설명: 선택한 도서에 교환을 요청한다.



\## 5. 교환 요청 목록 조회



\- Method: GET

\- URL: /exchange-requests

\- 설명: 교환 요청 목록을 조회한다.
