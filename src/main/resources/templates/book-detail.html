⚡ Redis 상세 조회 캐시

자주 조회되는 도서 상세 정보를 Redis 메모리에 캐싱하여 동일한 도서를 다시 조회할 때 MySQL에 반복적으로 접근하지 않고 Redis에서 빠르게 데이터를 가져옵니다.

캐시 상태 HIT MISS
캐시 Key book:1
데이터 출처 Redis Cache MySQL
현재 조회 흐름
도서 상세 요청 → Redis 확인 → HIT → Redis 데이터 반환
도서 상세 요청 → Redis 확인 → MISS → MySQL 조회 → Redis 저장
Redis를 사용하는 이유
  • 반복되는 도서 상세 조회의 응답 속도를 높일 수 있습니다.
  • MySQL에 전달되는 반복 조회 요청을 줄일 수 있습니다.
  • 조회 요청이 많아져도 데이터베이스의 부하를 줄이는 데 도움이 됩니다.
  • 도서 ID를 book:{id} 형태의 Key로 관리하기 쉽습니다.
